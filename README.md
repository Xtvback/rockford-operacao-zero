# Rockford — Operação Zero

Protótipo experimental independente de hack and slash 2D no navegador, protagonizado por Rockford (universo USLORDS).

O jogo é gratuito, usa HTML/CSS/JavaScript, não exige instalação nem fornecedores de IA para jogar, e tem controlos táteis e de teclado.

A história e os desenhos são provisórios, não canónicos. Todos os direitos sobre o universo USLORDS e personagens reservados ao criador.
